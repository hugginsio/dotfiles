name: taskfile
description: Guidance for using Task with Taskfiles. Use this when Taskfile.y[a]ml is present in the project.
---

This project uses Task. If Task is available to you, you should always prefer to use it when appropriate. Always check the Taskfile before running operations like benchmarks, builds, and tests to see if there is a particular way these commands are used within the project.

If Task is not working, you can use `$tasks.[task].cmd` to view the command you should use.
